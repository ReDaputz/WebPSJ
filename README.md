# PSJ - Voices That Shape The World

PSJ adalah platform komunitas yang didedikasikan untuk memberdayakan pencerita muda, orator, dan jurnalis. Kami menyediakan ruang dan sumber daya bagi para pemimpin masa depan untuk mengasah kemampuan komunikasi dan penceritaan mereka di dunia nyata.

## Fitur Utama
* **The Orator:** Program komprehensif yang berfokus pada Penguasaan Public Speaking dan Jurnalisme Investigasi.
* **Komunitas & Jaringan:** Terhubung dengan pencerita lain karena di sini "You'll never speak alone".
* **Layanan:** Akses ke berbagai Workshops, Mentorship, Events, dan Resources.
